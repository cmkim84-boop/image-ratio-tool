# Q 이미지 편집기

이미지를 올리고 ① 원하는 비율로 자르기 ② 가로×세로 숫자로 확대·축소 ③ 모자이크 를 할 수 있는 윈도우 프로그램.

## 사용법
- 이미지를 창에 끌어다 놓거나 `이미지 추가` (여러 장 가능, 폴더도 가능)
- `자르기` (왼쪽 도구 막대): 오른쪽에서 비율 선택 → 미리보기에서 드래그(위치), 마우스 휠/슬라이더/모서리 드래그(크기)
- 출력 크기(px)에 가로×세로를 입력하면 그 비율로 크롭한 뒤 정확히 그 크기로 변환해 저장 (체크 해제하면 비율 모드로 복귀)
- `확대·축소` 도구
  - 가로×세로(px)를 입력하면 자르지 않고 사진 전체를 그 크기로 강제 변환 (비율 무시). 이 탭이 열린 상태에서 저장하면 확대·축소로 저장됨 (파일명 `원본이름_300x80.jpg`)
  - `사진 비율 유지` 체크 시 한쪽(마지막에 입력한 칸)만 기준으로 쓰고 다른 쪽은 사진마다 원래 비율로 자동 계산 (여러 장도 각자 계산)
  - 입력 크기가 원본보다 크면 경고 표시 (확대하면 흐려지거나 깨질 수 있음). 여러 장이면 몇 장이 해당하는지도 알려줌
- `모자이크` 도구
  - 모자이크: 상단 `모자이크 영역` 모드에서 원하는 곳을 드래그해 영역을 여러 개 추가 (사각형/원형). 영역 클릭=선택·이동, 모서리 드래그=크기, Delete=삭제. 강도 조절, 적용 on/off 가능. 영역은 이미지마다 따로 저장됨
- `설정` (왼쪽 아래 톱니바퀴 ⚙)
  - 워터마크: 팝업에서 `로고 이미지 선택` 후 켜면 저장 이미지 하단에 반투명으로 삽입 (투명도/크기/위치 조절, on/off). 켜져 있으면 톱니바퀴가 파란색으로 바뀝니다.
  - 설정과 로고 경로는 다음 실행 때도 유지됨
- `현재 이미지 저장` 또는 `전체 일괄 저장` → 저장 폴더 선택
- 저장 파일명: `원본이름_16x9.jpg` (원본 포맷 유지, 같은 이름이 있으면 `_2`, `_3` 붙음)

## 바로 실행 (Python 설치된 PC)
    pip install -r requirements.txt
    python app.py

## 설치 파일(Setup.exe) 만들기
결과물: `ImageRatioTool-Setup.exe` 하나. 더블클릭 → 설치 마법사 → 시작 메뉴/바탕화면 바로가기 생성, `설정 > 앱`에서 제거 가능. 관리자 권한 없이 내 계정에 설치됩니다.

- GitHub (추천): 저장소에 올린 뒤 Actions 탭 → `Build Windows installer` → Run workflow → 끝나면 Artifacts 의 `ImageRatioTool-Setup` 다운로드
- 윈도우 PC: Python 과 [Inno Setup 6](https://jrsoftware.org/isdl.php) 설치 후 `build.bat` 더블클릭 → `installer_output\ImageRatioTool-Setup.exe`
- 버전 변경: `installer.iss` 맨 위 `MyAppVersion` 수정. 같은 AppId 라서 새 설치 파일을 실행하면 업데이트(덮어쓰기)됩니다.
